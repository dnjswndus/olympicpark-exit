출차량은 공연 중 평소 수준으로 가다가 종료 후 급증하고, 30~45분간 처리 한계에 붙어 평평한 고원을 만들어요. 줄이 생기는 직접 원인은 출구의 처리 능력이에요. 공연장 2~3곳이 같은 시간대에 끝나는 날이 가장 심해요(3곳 동시: 최대 대기 중앙값 7.8분).

어떻게 분석했나

① 측정KSPO 주차장 입출차 약 193만 건을 분 단위 출구별 출차로 집계
② 연결KOPIS 공연 일정(공연장·시작·러닝타임)으로 공연별 예정 종료시각 계산
③ 모델출구별 대기행렬: 도착 = 평소 흐름 + 공연 차량 × 퇴장 분포(감마), 처리 = 출구 한계
④ 처방같은 모델에 방안을 넣어 대기 변화를 비교하고 시간 가치로 환산

검증: 74일 중 정점 시각이 실제와 10분 이내로 맞은 날 68%, 정점 크기가 ±15% 안인 날 65%, 15분 단위 R² 중앙값 0.48. 날마다 다른 퇴장 지연(예정 종료 후 몇 분 뒤 몰리나)은 날별로 보정했고, 2026 예보에는 같은 공연장 구성 유사일의 값을 그대로 써요.

한계와 가정

  • 대기는 출구 정산 게이트 앞만 계산해요. 주차장 내부 이동·도로 정체는 빠져 있어 체감 대기(후기상 30~60분)보다 작게 나와요.
  • 2025년 8~12월 입출차 데이터는 API 장애로 일부만 수집돼 1~7월로 모델을 만들었어요.
  • 방안 수치는 가정이에요: 시간 분산 = 공연 차량의 20%·40%를 30분 늦춤, 차선 추가 = 처리 한계 ×1.5, 시간 가치 = 차량 1대·1시간 2.4만 원(1.6명 × 1.5만 원).
  • 2026 공연 중 러닝타임 미공개 공연은 2시간으로 가정했어요.
