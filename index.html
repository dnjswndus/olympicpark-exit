날짜별 최적 대처 — 어떻게 고르나

  • 후보: 늦은 출차 주차비 혜택 5단계(없음 / 30분 동결 / 동결+2천 / +4천 / +6천 원) × 출구 분산 유/무 × 정산 속도 +0~30%(10% 단위) × 임시 차선(없음/북2/동2/남2) = 160가지 조합
  • 조건: 출구 최대 대기 3분 이하 (못 지키면 대기가 가장 짧은 조합)
  • 목표: 운영비 + 시간 손실(대기 차량·시간 × 2.4만 원) 최소. 차이가 5만 원 이내면 더 단순한 방안을 우선해요
  • 주차비 혜택: 올림픽공원 소형 주차요금 10분당 600원 기준으로, 종료 후 30분 동결 = 1,800원. 비용 = 늦게 나간 차량 수 × 혜택액(주차 수입 감소). 늦게 나가는 비율은 동결 10%, +2천 20%, +4천 30%, +6천 40%로 가정
  • 운영비 가정 (하루): 출구 분산 안내 15만 원(안내요원·전광판), 임시 차선 30만 원, 정산 속도 +10%당 10만 원(사전정산 안내·인력)
  • 결과 (2025년 74일): 시간 손실 + 운영비 7,364만 원 → 2,177만 원(−70%), 대기 3분 이내인 날 41일 → 74일. 37일은 평소 운영, 주차비 혜택은 6일에만 사용
  • 민감도: 참여율을 절반으로 보면 −66%(73일 달성), 두 배로 보면 −73%. 매일 일괄 할인(동결+2천 + 출구 분산)은 8,128만 원으로 현재보다 오히려 커요

한계와 가정

  • 대기는 출구 정산 게이트 앞만 계산해요. 주차장 내부 이동·도로 정체는 빠져 있어 체감 대기(후기상 30~60분)보다 작게 나와요.
  • 2025년 8~12월 입출차 데이터는 API 장애로 일부만 수집돼 1~7월로 모델을 만들었어요.
  • 방안 수치는 가정이에요: 주차비 혜택별 참여율(10~40%), 차선 추가 = 처리 한계 ×1.5, 시간 가치 = 차량 1대·1시간 2.4만 원(1.6명 × 1.5만 원). 주차요금은 공개 안내 기준이에요.
  • 2026 공연 중 러닝타임 미공개 공연은 2시간으로 가정했어요.
  • 운영비 단가는 공개 자료가 없어 가정한 값이에요. 기관의 실제 단가를 넣으면 추천이 바뀔 수 있어요.
